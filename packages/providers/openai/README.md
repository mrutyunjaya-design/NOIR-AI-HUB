# OpenAI Provider

Integration with OpenAI's API (https://platform.openai.com)

## Setup

1. Create account at https://platform.openai.com
2. Generate API key
3. Set environment variable:

```bash
OPENAI_API_KEY=sk-...
```

## Supported Models

- GPT-4 Turbo
- GPT-4
- GPT-3.5 Turbo

## Features

- ✅ Chat completion
- ✅ Streaming responses
- ✅ Vision (GPT-4 Turbo)
- ✅ Function calling (tools)
