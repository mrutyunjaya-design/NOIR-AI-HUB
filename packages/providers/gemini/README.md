# Google Gemini Provider

Integration with Google's Gemini API (https://ai.google.dev)

## Setup

1. Visit https://ai.google.dev
2. Generate API key
3. Set environment variable:

```bash
GEMINI_API_KEY=...
```

## Supported Models

- Gemini Pro
- Gemini Pro Vision

## Features

- ✅ Chat completion
- ✅ Streaming responses
- ✅ Vision (Pro Vision)
