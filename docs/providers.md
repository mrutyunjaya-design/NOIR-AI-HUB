## Integration Architecture

NOIR supports multiple integration patterns:

### Provider Adapters
Each provider has a dedicated adapter implementing the unified interface:

```typescript
export interface AIProvider {
  id: string;
  name: string;
  category: 'chat' | 'coding' | 'image' | 'video' | 'audio' | 'research' | 'local';
  listModels(): Promise<Model[]>;
  chat(request: ChatRequest): Promise<AIResponse>;
  stream(request: ChatRequest): AsyncIterable<AIStreamChunk>;
  healthCheck(): Promise<HealthStatus>;
}
```

### Categories
- **chat** — Conversational LLMs
- **coding** — Code generation & completion
- **research** — Academic & web research
- **image** — Image generation
- **video** — Video generation
- **audio** — Voice & sound generation
- **local** — Self-hosted models

### Adding a Provider

1. Create adapter: `packages/providers/[provider-name]/`
2. Implement `AIProvider` interface
3. Handle authentication (API key, OAuth, etc.)
4. Normalize responses to unified format
5. Add to provider registry
6. Test integration
7. Document setup

### BYOK (Bring Your Own Key)

Users can connect their own API credentials for any supported provider:

```
User connects OpenAI API key
    ↓
NOIR encrypts & stores securely
    ↓
User prompts are routed through their API key
    ↓
No NOIR infrastructure cost
    ↓
User pays provider directly
```
